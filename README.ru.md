## Что это такое?

Discord требует 10 МБ? Gmail не принимает файлы больше 25 МБ? А ваше видео весит 180 МБ? **Slip решает эту проблему.**

Он рассчитывает точный битрейт, необходимый для того, чтобы ваше видео гарантированно уместилось **в рамки лимита**, используя двухпроходное кодирование (two-pass encoding). Сжатие происходит локально на вашем компьютере с помощью FFmpeg. Никакие данные не отправляются на сторонние серверы — ваше видео никогда не покидает ваше устройство.

| Преимущества | Описание |
|---|---|
| **Точность размера** | Двухпроходное кодирование с запасом безопасности. Видео уложится точно под лимит, а не превысит его. |
| **Высокая скорость** | Встроенный FFmpeg с поддержкой аппаратного ускорения на ПК. |
| **Кроссплатформенность** | Работает на macOS, Windows, Linux, Android и в браузере (Web) с единым интерфейсом. |
| **Абсолютная приватность** | Работает на 100% локально. Без регистрации, без отправки файлов на сервера и без телеметрии. |

## Как это работает?

Slip представляет собой **единое React-приложение**, которое одинаково запускается как на ПК (внутри Tauri), так и в веб-браузере, используя подключаемые движки сжатия:

```
                 ┌───────────────────────────────┐
                 │   React + TypeScript + Tailwind│
                 │   Сжатие · История · Настройки│
                 └───────────────┬───────────────┘
                                 │ Интерфейс CompressEngine
              ┌──────────────────┴──────────────────┐
              ▼                                      ▼
   ┌──────────────────────┐              ┌────────────────────────┐
   │  NativeEngine        │              │  WasmEngine            │
   │  Tauri → Rust        │              │  ffmpeg.wasm (браузер) │
   │  Встроенный FFmpeg   │              │  Работа без установки  │
   │  2-проходное, HW     │              │  1-проходное сжатие    │
   └──────────────────────┘              └────────────────────────┘
```

Движок выбирается автоматически: в десктопной версии (Tauri) используется нативный быстрый кодировщик, в браузере — WASM-версия. Интерфейс, формулы расчёта и дизайн-система являются общими.

### Расчёт битрейта

Основная логика расчёта размера находится в [`src/engine/bitrate.ts`](src/engine/bitrate.ts):

```
total_bits   = target_bytes × 8 × safety_margin
video_bits   = total_bits − audio_bits − container_overhead
video_bitrate = video_bits ÷ duration          (не превышая исходный битрейт)
```

Битрейт аудио автоматически снижается при очень жестких лимитах, разрешение подстраивается под ограничения, а итоговый план кодирования проверяется перед началом сжатия.

```

│   │   └── index.ts          #   выбор движка

│   │   └── ui/               # Базовые примитивы (Button, Card, Dropdown, Slider...)
│   ├── screens/              # Экраны приложения (Сжатие, История, Настройки, Главный)
│   ├── hooks/useCompressor.ts# Стейт-машина процесса сжатия
│   └── lib/                  # Стейт (zustand), хелперы, форматирование
├── src-tauri/                # Бэкенд на Rust
│   └── src/
│       ├── lib.rs            # Tauri команды и менеджер задач
│       ├── ffmpeg.rs         # поиск FFmpeg и версия
│       ├── probe.rs          # ffprobe → VideoInfo (информация о файле)
│       └── compress.rs       # двухпроходной кодировщик + прогресс
├── scripts/gen_icons.py      # Генератор иконок без зависимостей
└── .github/workflows/        # CI/CD: веб-сборка + десктопные установщики
```

## Разработка

**Требования:** Node 20+, Rust (stable) и FFmpeg в вашей переменной PATH (или путь к нему можно настроить прямо в приложении).

```bash
# Установка зависимостей
npm install

# Запуск веб-версии (PWA)
npm run dev

# Запуск десктопной версии (Tauri)
npm run tauri:dev
```

### Сборка

```bash
npm run build          # Веб-версия  → dist/
npm run tauri:build    # Нативные сборщики под текущую ОС
```

Иконки приложения можно сгенерировать командой:

```bash
python3 scripts/gen_icons.py     # затем: npm run tauri icon src-tauri/icons/icon.png
```

## Дизайн-система

Монохромная, лаконичная, минималистичная — эстетика Apple, созданная разработчиками для разработчиков.

- **Цвета** — чистый градиент серого (`#000 → #FFF`), зеленый для успешных действий, красный только для ошибок.
- **Шрифты** — семейство шрифтов Inter, крупные заголовки, свободный ритм отступов.
- **Иконки** — Lucide с тонкими линиями.
- **Скругления** — мягкие углы 8–16px.
- **Анимации** — плавные переходы (150мс), изменение прозрачности и масштаба.

Дизайн-токены объявлены как CSS-переменные в [`src/index.css`](src/index.css) и используются через стандартные классы Tailwind CSS. Поддерживается полноценная темная и светлая темы.
